# Qwinsta.TUI 0.1.0

Прототип общего интерфейса для административных инструментов под **Windows PowerShell 5.1 Desktop**. Проверь внешний вид и управление до фиксации стабильного API.

## Быстрый запуск

1. Скачай ZIP ветки с прототипом или клонируй эту ветку репозитория.
2. Распакуй архив целиком. Сохрани взаимное расположение файлов.
3. Открой `scripts/tui/Start-Demo.cmd` обычным двойным щелчком.

Демо работает локально, не обращается к серверам, не меняет настройки системы, не сохраняет введенные значения и не требует прав администратора. В таблице 32 вымышленных сервера. Для пароля используй тестовое значение.

Если политика исполнения запрещает запуск, используй согласованный в своей среде способ запуска или подписи. BAT не меняет политику исполнения. Для доверенного скачанного архива блокировку загрузки можно снять в свойствах архива до распаковки, если это разрешено правилами среды.

Альтернативный запуск из Windows PowerShell 5.1 в папке репозитория:

```powershell
cls
& .\scripts\tui\examples\Demo.ps1
```

## Что проверить

- Стрелки и Enter выбирают пункт; цифры 1–9 открывают соответствующий пункт.
- Escape и Ctrl+C возвращают назад; в главном меню завершают демо.
- Home / End и PgUp / PgDn перемещают выбор по длинному списку.
- `/` открывает поиск по отображаемым столбцам таблицы. Пустой запрос снимает фильтр.
- В поле ввода работают стрелки, Home / End, Backspace, Delete и Ctrl+U.
- Подтверждение по умолчанию отвечает «Нет».
- Во время прогресса Escape запрашивает отмену, демо ее обрабатывает.
- При уменьшении окна ниже 60 × 20 отображается просьба увеличить окно. Escape остается доступным.
- После выхода восстанавливаются цвета, видимость курсора и обработка Ctrl+C.

## Ограничения

API 0.x экспериментальный. Постоянная совместимость начинается с первой стабильной версии 1.0.0 после проверки интеграции с реальными проектами.

На этом этапе нет автоматического обновления, кеша, BAT-загрузчика с GitHub и обработчика `https://qwinsta.ru/scripts/tui`. Эта команда пока не публикуется как рабочий способ запуска.

Целевые ОС: Windows 10, Windows Server 2016, 2019, 2022. Фактические результаты проверок смотри в Actions и [матрице](../../docs/tui/testing.md); перечень целевых ОС сам по себе не означает завершенную проверку каждой из них.

Нужна интерактивная консоль: обычное окно PowerShell или Windows Terminal с `powershell.exe`. PS 7, ISE, перенаправление ввода/вывода и фоновый запуск для этого прототипа не поддерживаются. Шрифт должен содержать кириллицу и символы навигации. Экраны рассчитаны на символы обычной ширины; корректная ширина emoji и CJK не гарантируется.

Публичную лицензию следует выбрать перед стабильным выпуском; в этом изменении лицензия не назначается.
