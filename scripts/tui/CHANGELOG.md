# Изменения Qwinsta.TUI

## 0.1.0 — прототип, 16.10.2026

- Общий заголовок, статус приложения и темное оформление с зеленым акцентом.
- Меню и вложенные экраны, клавиатурная навигация, быстрый выбор цифрой.
- Таблица с выбором, поиском и прокруткой.
- Редактирование текста и скрытый ввод SecureString.
- Подтверждение с отказом по умолчанию.
- Информационные сообщения, результаты и ошибки с прокруткой.
- Отображение прогресса с передачей запроса отмены приложению.
- Обработка изменения размера окна и восстановление настроек консоли.
- Локальный BAT/CMD-запуск, минимальный пример подключения, справочник API.
- Проверки сценариев с тестовым вводом в настоящем PS 5.1 через GitHub Actions.

Это еще не стабильный API и не система автоматического обновления.
