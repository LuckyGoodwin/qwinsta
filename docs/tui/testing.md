# Проверка прототипа

## Автоматическая проверка

Из Windows PowerShell 5.1, в корне репозитория:

```powershell
cls
& .\scripts\tui\tests\Test-QwTui.ps1
```

Альтернатива: `examples/Demo.ps1 -Check` из папки каркаса. Внешние тестовые модули не требуются.

Набор проверяет синтаксис всех PS-файлов настоящим парсером 5.1, UTF-8 BOM, манифест, границы экспорта, версию и встроенную справку. Сценарии ввода проходят через те же функции меню, таблицы, полей и сообщений, что используются демо, с подставленным терминальным вводом и записью кадров.

Проверяются прокрутка, цифровой выбор, отмена, пустые данные, повторные Id, изменение размера окна, поиск, идентичность возвращаемой строки, редактирование, обязательность и длина поля, различие пустой строки и отмены, скрытый ввод, подтверждение по умолчанию, прогресс, размеры кадра и отсутствие лишних результатов в конвейере.

GitHub Actions `TUI prototype checks` запускает этот же набор через `shell: powershell` на Windows Server 2022. Проверка версии не позволяет случайно заменить PS 5.1 на PS 7. После успешной проверки доступны артефакты ZIP демо и JSON первого экрана.

Адаптер терминала в тестах — внутренняя деталь, не публичный способ подключения проекта. Автотесты не подтверждают правильность реального шрифта, клавиатуры и перерисовки конкретного терминала.

## Ручной сценарий

1. Запусти Start-Demo.cmd от обычного пользователя без сети.
2. Пройди все шесть пунктов главного меню. Проверь, что их назначение понятно без инструкции.
3. В списке серверов проверь End, Home, PgDn, PgUp и стрелки; открой строку и вернись.
4. Нажми `/`, найди `srv-demo-11`, попробуй запрос без результатов, затем сними фильтр пустым запросом. Отмена поиска должна сохранить прежний фильтр.
5. Проверь пустой список во вложенном меню: Enter ничего не выбирает, Escape возвращает.
6. Введи кириллицу, вставь короткую однострочную строку, отредактируй начало и середину, удали символы, очисти через Ctrl+U. Убедись, что отмена не считается принятым значением.
7. Введи тестовый пароль: символы видны только как звездочки; после принятия пароль не показывается.
8. Открой подтверждение и нажми Enter сразу: результат должен быть «Нет». Затем явно выбери «Да».
9. Отмени прогресс через Escape; отдельно дождись 100%. Демо должно показать соответствующий результат.
10. Прокрути длинное сообщение до конца и обратно.
11. Уменьши окно до 60 × 20, затем ниже минимума и снова увеличь. Выбор не должен самопроизвольно сработать.
12. Повтори в обычной консоли и Windows Terminal с PS 5.1, если Terminal установлен.
13. Проверь Ctrl+C на разных экранах и выход из главного меню. Цвета, курсор и обычный режим Ctrl+C должны восстановиться.
14. Запусти из пути с пробелами и кириллицей; затем из другого текущего каталога. При необходимости повтори с повышением прав.

Для замечаний укажи ОС и сборку, вывод `$PSVersionTable.PSVersion`, терминал, размер окна, шаги и ожидаемый результат. Не присылай настоящие пароли.

## Следующий набор проверок

Автообновление, SHA-256, сетевые сбои, кеш, одновременное обновление, совместимость исторических выпусков и реальные проекты появятся вместе с соответствующей реализацией. В прототипе 0.1.0 эти возможности не имитируются как готовые.
