# Qwinsta.TUI

Общий каркас консольных меню для административных инструментов под **Windows PowerShell 5.1 Desktop**.

## Текущий этап

Версия **0.1.0** — прототип внешнего вида, управления и способа подключения. Он содержит тестовое приложение, а не готовый менеджер серверов.

Проект передает названия экранов, пункты меню и данные. Каркас отрисовывает их и возвращает выбор. Прикладные действия выполняет проект.

## Запуск

Скачай исходники соответствующей ветки или выпуска репозитория [LuckyGoodwin/qwinsta](https://github.com/LuckyGoodwin/qwinsta). Распакуй целиком и запусти `scripts/tui/Start-Demo.cmd`.

Демо не требует интернета или прав администратора. Оно не выполняет сетевых запросов, не меняет систему и не записывает введенные значения. Для проверки скрытого ввода используй вымышленный пароль.

Требуется интерактивная консоль шириной от 60 символов и высотой от 20 строк. В PowerShell ISE и PS 7 прототип не запускается. В Windows Terminal нужно выбрать именно Windows PowerShell 5.1.

BAT не меняет политику исполнения. Если запуск запрещен политикой, используй разрешенный в своей среде способ запуска или подписи. Для доверенного архива при необходимости сними блокировку загрузки перед распаковкой, если это разрешено.

## Демонстрационные экраны

| Экран | Что проверяется |
|---|---|
| Список серверов | 32 тестовые строки, выбор, поиск, прокрутка, карточка |
| Ввод данных | Редактирование обычного текста и скрытый ввод |
| Подтверждение | Согласие, отказ, отмена и значение по умолчанию |
| Ход выполнения | Проценты, текущий этап и запрос отмены |
| Результаты и ошибки | Сообщения разных типов и длинный текст |
| Вложенное меню | Переходы между экранами и пустой список |

Стрелки выбирают пункт, Enter открывает, Escape возвращает назад. В главном меню Escape закрывает демо. Цифры 1–9 выбирают пункт по его номеру. В таблице `/` открывает поиск; пустая строка запроса возвращает все данные.

## Подключение

Минимальный пример находится в `scripts/tui/examples/Minimal.ps1`. Обязательно закрывай сессию в `finally`, чтобы восстановить настройки консоли при ошибке проекта.

```powershell
cls
Import-Module .\scripts\tui\Qwinsta.TUI.psd1
$ui = $null
try {
    $ui = Start-QwTuiSession -Application 'Мой инструмент' -Version '0.1.0'
    $id = Show-QwMenu $ui 'Действия' @(
        @{ Id = 'list'; Title = 'Показать список'; Description = 'Пример действия' }
    )
    if ($id -eq 'list') {
        Show-QwMessage $ui 'Готово' -Message 'Обработчик находится в проекте.'
    }
} finally {
    Stop-QwTuiSession $ui
}
```

Все вызовы, параметры, результаты и ограничения описаны в [справочнике API](api.md). Порядок проверки — в [инструкции тестирования](testing.md).
