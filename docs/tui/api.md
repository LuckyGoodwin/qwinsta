# Справочник API 0.1.0

Все девять экспортируемых функций описаны ниже. API экспериментальный до 1.0.0. Внутренние функции модуля не являются интерфейсом подключения проекта.

## Общие правила

- Импорт: `Import-Module .\scripts\tui\Qwinsta.TUI.psd1`.
- Среда интерактивного запуска: Windows PowerShell 5.1 Desktop, ConsoleHost, без перенаправления ввода/вывода.
- `Session` — объект из `Start-QwTuiSession`; его внутренние свойства не меняй.
- В один момент активна одна сессия. Экраны вызываются последовательно.
- Экраны синхронные, кроме `Show-QwProgress`, который рисует один кадр и сразу возвращается.
- Каркас ничего не пишет в журналы, не сохраняет пользовательские значения и не вызывает сетевые или административные команды.
- Текст отрисовки не попадает в конвейер объектов PowerShell. Функции возвращают только документированный результат.
- Escape и Ctrl+C отменяют текущий экран. В демо Ctrl+C не является аварийным завершением всего процесса.
- Неправильные аргументы и закрытая сессия вызывают ошибку; отмена не считается ошибкой.
- Окно меньше 60 × 20 блокирует обычный выбор, но позволяет отмену. Прогресс остается информационным, прикладную работу контролирует вызывающий код.
- После начала прикладного действия каркас не выполняет автоматический повтор.
- Имена функций с общими параметрами поддерживают стандартные параметры PowerShell вроде `-ErrorAction`; они не перечислены в таблицах.

## Get-QwTuiInfo

**Назначение:** вернуть сведения о загруженном каркасе и поддерживаемых возможностях. Параметров нет; консольная сессия не нужна. Появилась в 0.1.0.

Результат — объект с `Version` (Version), `Api` (строка `experimental`), `Runtime` (строка) и `Capabilities` (строки): `Menu`, `Table`, `Table.Search`, `TextInput`, `SecureInput`, `Confirm`, `Message`, `Progress`.

Пример: `(Get-QwTuiInfo).Capabilities -contains 'Table.Search'`. Проверка возможности нужна проекту перед использованием необязательного расширения. При отсутствии проверки и самой функции старый модуль не сможет выполнить неизвестный вызов.

## Start-QwTuiSession

**Назначение:** проверить среду, сохранить настройки консоли и открыть сессию. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Application | String | Да, непустое имя приложения |
| Version | String | Нет, `0.1.0`; версия приложения для заголовка |
| Status | String | Нет, пустая строка; краткое состояние от проекта |

Проверяет PS 5.1 Desktop, ConsoleHost, отсутствие перенаправления и другой активной сессии. Сохраняет цвета, видимость курсора и режим Ctrl+C. Очищает экран, скрывает курсор, включает получение Ctrl+C как клавиши. Возвращает объект Session.

Ошибки: неподдерживаемая среда, активная сессия, недоступная консоль. Самостоятельно не диагностирует систему и не вычисляет Status.

Пример: `$ui = Start-QwTuiSession -Application 'Серверы' -Version '1.2.0' -Status 'Локальные данные'`.

## Stop-QwTuiSession

**Назначение:** закрыть сессию и восстановить настройки консоли. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object / null | Нет, null; позиция 0 |

Результата нет. Null и повторное закрытие безопасны. Экран очищается; прежнее содержимое экрана не восстанавливается. Цвета, видимость курсора и режим Ctrl+C возвращаются к исходным значениям. Ошибка консоли возможна при ее закрытии извне; остальные этапы восстановления все равно выполняются через finally.

Пример: `finally { Stop-QwTuiSession $ui }`. Окружай этим блоком весь код после открытия сессии.

## Show-QwMenu

**Назначение:** показать меню и получить Id выбранного пункта. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1 |
| Items | Object[] | Да; позиция 2; пустой массив допустим |
| Description | String | Нет, пустая строка |

Каждый пункт — словарь или объект: `Id` (непустая строка), `Title` (непустая строка), `Description` (необязательная строка). Id уникален без учета регистра. Порядок пунктов сохраняется.

Возвращает строку Id; Escape / Ctrl+C возвращают null. Ничего не выполняет за проект. Enter выбирает выделенный пункт, цифры 1–9 сразу выбирают соответствующий пункт из первых девяти. Стрелки, Home / End, PgUp / PgDn перемещают выбор; за границу списка выбор не переходит. Пустой список позволяет только возврат.

Ошибки: закрытая сессия, пустой или повторяющийся Id, пустой Title.

Пример: `$id = Show-QwMenu $ui 'Действия' @(@{ Id = 'list'; Title = 'Список'; Description = 'Показать данные' })`. Проект сравнивает `$id` с `'list'` и выполняет свой обработчик; null означает возврат.

## Show-QwTable

**Назначение:** показать таблицу с выбором, прокруткой и поиском. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1 |
| Rows | Object[] | Да; позиция 2; пустой массив допустим |
| Columns | Object[] | Да; позиция 3; от 1 до 6 столбцов |
| Description | String | Нет, пустая строка |

Строки — исходные объекты или словари. Столбец: `Key` (имя свойства строки), `Title` (заголовок), `Width` (необязательный положительный целочисленный вес ширины, по умолчанию 1). Вес распределяет доступное место; это не фиксированное число символов. Отсутствующее свойство строки отображается пустым. Длинные значения сокращаются многоточием.

Enter возвращает исходный выбранный объект, а не его копию. Escape / Ctrl+C возвращают null. `/` открывает поле поиска; поиск без учета регистра идет только по отображаемым столбцам. Пустой запрос снимает фильтр, отмена редактирования сохраняет прежний запрос. При новом фильтре выбор перемещается на первую строку. Пустой результат поиска не выбирается по Enter.

Ошибки: закрытая сессия, неподходящее число столбцов, пустые Key / Title, неположительный Width.

Пример: `$row = Show-QwTable $ui 'Серверы' @([pscustomobject]@{ Name = 'srv-01' }) @(@{ Key = 'Name'; Title = 'Сервер' })`. Если `$null -ne $row`, проект использует `$row.Name`.

## Read-QwText

**Назначение:** редактирование текста или скрытый ввод. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1 |
| Description | String | Нет, пустая строка |
| Value | String | Нет, пустая строка; начальный обычный текст |
| MaxLength | Int32 | Нет, 256; от 1 до 4096 |
| AllowEmpty | Switch | Нет, выключен |
| AsSecureString | Switch | Нет, выключен; запрещено сочетание с Value |

Enter возвращает String или read-only SecureString. Escape / Ctrl+C возвращают null. Пустая строка при AllowEmpty отличается от отмены. Работают стрелки, Home / End, Backspace, Delete и Ctrl+U. Лимит измеряется в кодовых единицах .NET Char. Нет вставки многострочного текста, проверки адресов или прикладной валидации.

Скрытый ввод хранит символы в SecureString и отрисовывает только звездочки. Отмененный буфер освобождается каркасом; возвращенный SecureString освобождает проект через Dispose. Не передавай его в журналы и не преобразовывай в обычный текст без необходимости. Каркас не контролирует средства записи сессии, установленные вне приложения.

Ошибки: закрытая сессия, Value длиннее MaxLength, Value вместе с AsSecureString, неверный диапазон MaxLength.

Примеры: `$name = Read-QwText $ui 'Имя' -Value 'srv-01'`; `$secret = Read-QwText $ui 'Пароль' -AsSecureString`. Проверяй null; для `$secret` используй `try { ... } finally { $secret.Dispose() }` после проверки на null.

## Confirm-QwAction

**Назначение:** явное подтверждение действия. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1; вопрос о действии |
| Description | String | Нет, пустая строка; последствия действия |

Возвращает Boolean. По умолчанию выделено «Нет». Только явный выбор «Да» дает true; отказ и Escape / Ctrl+C дают false. Использует Show-QwMenu и наследует его требования к сессии. Само действие не выполняет.

Пример: `if (Confirm-QwAction $ui 'Продолжить?' -Description 'Тестовое действие') { ... }`.

## Show-QwMessage

**Назначение:** показать информационный текст, результат или ошибку. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1 |
| Message | String[] | Да; пустые строки и массив допустимы |
| Kind | String | Нет, Info; варианты Info / Success / Error |

Результата нет. Kind меняет только цвет, не генерирует исключение и не записывает журнал. Длинные строки переносятся по ширине, в том числе посреди слова. Стрелки, Home / End и PgUp / PgDn прокручивают; Enter / Escape / Ctrl+C закрывают экран.

Ошибки: закрытая сессия, неизвестный Kind.

Пример: `Show-QwMessage $ui 'Готово' -Message @('Проверка завершена.', 'Ошибок нет.') -Kind Success`.

## Show-QwProgress

**Назначение:** отрисовать один кадр прогресса и вернуть запрос продолжения. Появилась в 0.1.0.

| Параметр | Тип | Обязательный / значение по умолчанию |
|---|---|---|
| Session | Object | Да; позиция 0 |
| Title | String | Да; позиция 1 |
| PercentComplete | Int32 | Да, от 0 до 100 |
| Description | String | Нет, пустая строка; текущий этап от проекта |

Возвращает true для продолжения, false при считанной Escape / Ctrl+C. Не запускает работу, не измеряет ее, не ждет завершения и не прерывает сторонние команды. Проект регулярно вызывает функцию и сам обрабатывает false. Если приложение блокируется надолго между вызовами, своевременная отмена и перерисовка не гарантируются. Размер окна учитывается при следующем кадре.

Ошибки: закрытая сессия, процент вне диапазона.

Пример: `if (-not (Show-QwProgress $ui 'Проверка' -PercentComplete 25 -Description 'Чтение данных')) { break }` внутри цикла проекта. Полный пример — `scripts/tui/examples/Demo.ps1`.
